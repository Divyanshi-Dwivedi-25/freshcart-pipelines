# FreshCart Pipelines

Data Engineering Assignment: From Git to Gold

## Project Overview

This project includes:

1. Git and CI/CD
2. FreshCart ELT Pipeline
3. Machine Learning Pipeline using Mage
4. Food Order Streaming using RabbitMQ

## Technologies Used

- Python
- Git and GitHub
- Snowflake
- Mage
- RabbitMQ
- Pytest
## Installation and Setup

1. Clone the repository:

   git clone https://github.com/Divyanshi-Dwivedi-25/freshcart-pipelines.git

2. Navigate to the project directory:

   cd freshcart-pipelines

3. Install dependencies:

   pip install -r requirements.txt

## Running Tests

Run the following command to execute automated tests:

   PYTHONPATH=. pytest
